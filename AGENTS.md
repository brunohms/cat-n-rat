# Agent guidelines

## Language

- All documentation must be written in English: READMEs, Markdown files, docstrings, code comments and API descriptions (e.g. FastAPI/Pydantic `description` fields).
- All code identifiers must be in English: functions, methods, classes, variables, modules, routes and configuration keys.
- User-facing strings in code (log messages, error messages, HTTP error details) must also be in English.
- This applies even when the conversation with the agent happens in another language.
